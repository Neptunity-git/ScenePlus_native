# ScenePlus+ v2.4.1 Release Notes

## 🐛 バグ修正 ＆ 画面最適化 (Bug Fixes & Display Optimization)

* **高DPI・マルチ解像度環境におけるウィンドウ表示の完全安定化**
  * 異なる解像度やDPI拡大率（125%、150%、200%等）のPC環境で、表示サイズが不安定になったり縮小・変調してしまう問題を修正しました。
  * ズーム倍率計算の基準をメインプロセスが保持する不変の物理ディスプレイ bounds に固定することで、倍率計算の無限フィードバックループ（拡大・縮小の反復現象）を完全に排除しました。

* **スリープ復帰時・画面切り替え時の倍率自動保持**
  * PCがスリープから復帰した際や、マルチモニターの接続切替時に、表示倍率が一時的なデフォルト値（100%や200%）に固定されてしまう問題を修正しました。
  * 画面表示の準備が完了したタイミングで本来の正確な画面比例倍率へ自動復元されます。
