# ScenePlus+ v2.3.0 Release Notes

## 🚀 新機能 (New Features)

* **ライブ・ホットリロード (HMR) の実装**
  * エフェクトコード（`index.js` 等）を外部エディタで編集して保存（Ctrl+S）すると、アプリを再起動することなく**瞬時に再生中のエフェクトに変更が反映**されるようになりました。
  * 開発時の待ち時間がゼロになり、パーティクルや色の微調整が非常に快適に行えます。

* **「外部エディタで開発」機能の追加**
  * ライブラリのエフェクトカードに新しく「`</>`（ソースを編集）」ボタンを追加しました。
  * 既存のエフェクトをワンクリックで開発用（`dev_`）として複製（フォーク）し、自動でVSCode等の外部エディタで開くことができます。
  * 既存のパッケージを壊すことなく、安全にカスタマイズを楽しむことが可能です。

## ✨ 改善・仕様変更 (Improvements & Changes)

* **ネットワーク・同期機能との完全互換**
  * 外部エディタ用に複製された `dev_` エフェクトも、通常のエフェクトと同様にネットワーク越しのOSC同期やダウンロードの対象となります。
  * 複数台の端末間でも、手元で改変したエフェクトがそのままシームレスに同期・再生されるよう内部仕様を最適化しました。

* **UIレイアウトの最適化**
  * エフェクトカード上の「CODE」や「HOLD」といったメタタグをエフェクト名の上に配置し、より長いエフェクト名が途切れずに表示できるようスペースを確保しました。

* **安全機能の強化 (セーフティネット)**
  * 「`</>`」ボタンでの誤爆フォークを防ぐため、実行前に確認ダイアログを表示するようにしました。
  * 外部エディタ（VSCodeなど）でファイルを開いている最中にエフェクトを削除しようとした場合、内部データが破損（半端に削除）するのを防ぐため、削除を安全にブロックして警告を表示する機能を搭載しました。

## 🐛 バグ修正 (Bug Fixes)

* フォルダ読み込み時に、別々のフォルダでも中の `meta.json` の内容が完全に一致しているとIDが衝突して上書きされてしまう問題を修正し、フォルダの絶対パス基準で安全に独立したIDを生成するように修正しました。
* `import()` のモジュールキャッシュに起因する、JSON構文エラーやホットリロードの不発問題を解消しました（キャッシュバスティング処理の最適化）。
