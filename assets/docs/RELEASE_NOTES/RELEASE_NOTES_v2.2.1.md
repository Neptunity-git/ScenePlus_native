# 🚀 ScenePlus+ v2.2.1 Release Notes

> **ScenePlus+ v2.2.1** では、**エフェクト名のインライン編集（ダブルクリック / スタイリッシュSVGアイコン）**、高解像度・マルチアスペクト比画面での **表示見切れ問題の完全解消**、および **付属サンプルエフェクトの最適化** を適用したマイナー修正・機能強化パッチです！

---

## 🌟 v2.2.1 の主な新機能・改善点

### 1. ✏️ エフェクト名の直感的なインライン編集
- **インラインテキスト編集機能**
  - エフェクトカード上の **ペンSVGアイコン** または **タイトル部分をダブルクリック** することで、その場で直接名前を編集できるインライン入力フォームが起動します。
  - `Enter` キー押下または枠外クリックで新名称が即座に保存されます。
- **スタイリッシュなモノクロ SVG ベクターアイコン**
  - 絵文字アイコン（✏️ / 🗑️）を廃止し、サイバーパンクテーマに馴染む洗練された **モノクロ SVG ベクターアイコン** に刷新しました。
- **UI のシンプル化**
  - 使用頻度の低かったプレビュー再生ボタン（▶）を削除し、カードデザインをすっきりコンパクトに洗練させました。

---

### 2. 🖥️ 16:10 ディスプレイ & 200% 表示拡大での見切れ完全解消
- **縦横比（アスペクト比）両対応レスポンシブスケーリング (`renderer.ts`)**
  - 2880x1800 (200% 拡大 / 論理1440x900) などの画面環境において、左右の `MODE INFO` や `SYSTEM LOG` パネルが画面外へはみ出る問題を解消。
  - `Math.min(currentWidth / 1280, currentHeight / 720)` による縦横比両対応の自動スケーリングを適用し、いかなる表示倍率・縦横比でも UI 全体が完璧に画面内に収まるよう改善しました。

---

### 3. 📦 付属サンプルエフェクトの選定 & バイナリパッケージ化
- **初期サンプルエフェクトの限定**
  - アプリ初回起動時のウェルカムパックを以下の **厳選2作品のみ** に絞り込みました：
    1. `Absolute_Cyber_Sync`
    2. `Desktop_Virus_Joke`
- **`Desktop_Virus_Joke` の `.scenefx` パッケージ化**
  - ウイルス風 Canvas エフェクトを正式なバイナリ形式である `.scenefx` (ZIPパッケージ) へコンパイル生成しました。
