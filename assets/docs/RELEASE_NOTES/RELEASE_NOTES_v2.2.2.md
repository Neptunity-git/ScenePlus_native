# 🚀 ScenePlus+ v2.2.2 Release Notes

> **ScenePlus+ v2.2.2** は、**マルチPC通信・連動発火機能の完全復旧**、**LANネットワークスキャンUIの洗練＆自端末フィルタリング**、**SOLID原則に基づくコードベースの徹底リファクタリング**、および **スマートアンインストーラー** を適用した安定性・保守性向上パッチリリースです！

---

## 🌟 v2.2.2 の主な新機能・改善点

### 1. 📡 マルチPCリアルタイム連動発火 & LANネットワーク自動発見の復旧
- **OSC リアルタイム連動発火 (`/sceneplus/play` / `/sceneplus/stop`)**
  - TRANSMIT（送信）モードのPCでキー打鍵した際、接続先 RECEIVE（受信）モードのPCへ即座にOSCトリガー信号を送信し、リモートPC上でエフェクトが同時発火・停止するように復旧しました。
- **LAN サブネット自動検出 (`SCAN NETWORK`)**
  - サブネットブロードキャスト (`${subnet}.255`) およびユニキャストスキャンにより、同一ネットワーク上の ScenePlus 受信機を自動発見します。

---

### 2. 🎨 スキャン UI のサイバーパンクデザイン刷新 & 自端末除外
- **自端末 IP の自動フィルタリング**
  - スキャン結果から送信機自身の IP アドレス（`192.168.x.x` や `127.0.0.1`）を自動除外。同一ネットワーク内の相手 PC のみがリスト表示されるよう改善しました。
- **IPアドレスの視認性を極限まで高めた「全域クリック可能カード」**
  - 重なって文字が見えなくなっていた `CONNECT` ボタンを廃止し、**IPアドレスが書かれたカード全体をクリックして接続できる直感的なインタラクション**に刷新。
  - アドレス末尾の数字（下6桁等）まで100%はっきり視認できる、ホバー光彩付きサイバーパンクカードデザインを採用しました。

---

### 3. 🏛️ SOLID 原則に基づくアーキテクチャ再構築
- **DIP（依存性逆転の原則）**: `src/shared/interfaces.ts` を新設し、各マネージャー間の結合を具象クラスから抽象インターフェースへ分離。
- **OCP（開放閉鎖の原則）**: `RendererIPC.ts` に Map ベースの OSC ディスパッチャーを導入。既存コードを変更せず新しいOSCコマンドを追加拡張可能に。
- **SRP（単一責任の原則）**: `renderer.ts` から DOM 描画処理を `UIManager.ts` へ完全移譲し、エントリーポイントの役割を明確化。

---

### 4. 🗑️ スマートアンインストーラー (%APPDATA% クリーン削除)
- Windows アンインストール時（`installer.nsh`）、`%APPDATA%\Roaming\sceneplus` 内のエフェクトデータおよび設定ファイルを完全に削除するか確認するメッセージダイアログを実装しました。
  - 「はい」を選択時のみ残留データを完全に消去します。
