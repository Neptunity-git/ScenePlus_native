# ScenePlus+ v2.4.2 Release Notes

## 🐛 バグ修正 ＆ サンプラー制御の正常化 (Bug Fixes & Sampler Logic)

* **設定パネルの「同時実行数リミット (maxN)」が正しく反映されるよう修正**
  * 設定画面（F9 -> `CONFIG`）の「**MAX CURRENT EFFECTS**（同時実行数リミット）」でユーザーが指定した上限値が、サンプラーエンジン（`EffectManager`）のFIFO（先入れ先出し）制御に正しく反映されず、内部で仮置きされていた固定値（20）のまま動作していた不具合を修正しました。
  * これにより、ユーザーが設定した値（例：1、3、5など）を超えて新しいエフェクトがトリガーされた際、設定値に沿って最も古いアクティブエフェクトが確実に自動破棄（終了演出および停止）されるようになり、意図した通りのサンプラーパフォーマンス管理が可能になりました。
