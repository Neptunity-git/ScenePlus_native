# ScenePlus+ v2.4.0 Release Notes

## 🚀 新機能 (New Features)

* **マルチモニター（動作モニター）選択機能の追加**
  * 設定画面（F9） -> `CONFIG` 内に「**TARGET DISPLAY**（動作モニター選択）」項目を新設しました。
  * 接続されているすべてのディスプレイ（解像度・拡大率）を自動検出し、ScenePlusのオーバーレイを表示させる対象モニターを自由に変更できます。
  * 設定保存（`SAVE & APPLY`）と同時に、アプリを再起動することなくその場で指定したモニターへオーバーレイ表示が移動します。
  * ディスプレイが切断された場合や未設定の場合は、安全にメインモニター（Primary Display）へ自動フォールバックします。

* **仮想Bin（フォルダ）管理 ＆ 右クリックコンテキストメニュー**
  * 増え続けるエフェクトライブラリを整理するため、**エクスプローラー風の仮想Bin（フォルダ）管理機能**を実装しました。
  * **100%仮想構造**: ディスク上の物理ファイル配置（`userData/effects/`）は一律フラットなまま維持されるため、パス切れやデータ損壊の心配が一切ありません。
  * **混在型カードデザイン**: Bin（フォルダ）カードはエフェクトカードと同等のサイバーパンク調デザインでグリッド上部に優先表示され、ダブルクリックで内部の階層にアクセスできます。ネスト（子Binの中に孫Bin）の作成も無制限に対応しています。
  * **ドラッグ＆ドロップ整理**: エフェクトカードをBinカードや上部のパスバー（Breadcrumbs）へドラッグ＆ドロップすることで、直感的に所属フォルダを移動できます。

## ✨ 改善・仕様変更 (Improvements & Changes)

* **直感的なインラインBin作成UI**
  * ライブラリ内を右クリックして `+ NEW BIN` を選択すると、グリッドの最先頭にネオンイエローに輝く入力用Binカードが出現します。
  * 外部ポップアップダイアログを挟むことなく、グリッド内で直接フォルダ名を入力して `Enter` キーを押すだけでBinを作成できる洗練された操作感を実現しました。

* **ネットワーク受信時の自動ルートBin配置**
  * 他の端末からエフェクト転送（SEND/RECEIVE/Sync）を受け取った際、新しく届いたエフェクトは自動的に受信側のルートBin（`/`）へ格納されます。
  * 相手側のフォルダ構成によって、自分のローカルライブラリのBin整理が乱されるのを防ぎます。

* **UIコンテキストメニューのF9非表示連動**
  * 右クリックポップアップメニューを表示したまま `F9` キーで設定画面全体を閉じた際や、画面の別エリアをクリックした際に、ポップアップが画面に残らずスムーズに自動消去されるよう連動を強化しました。

## 🐛 バグ修正 (Bug Fixes)

* **PCスリープ復帰時・画面切替時のDPIズームズレ（100%/200%化）の修正**
  * PCをスリープ復帰させた際やディスプレイの接続状態が変わった際に、150%固定などのUIズーム倍率が100%や200%へ誤変調・固定されてしまう問題を修正しました。
  * メインプロセス側で `powerMonitor`（`resume` / `unlock-screen`）および `screen` イベントを監視し、グラフィックドライバの再認識後に画面縦横比・DPIを再アサインして、本来の正しい比例倍率へ自動復元する仕組みを搭載しました。

* **エフェクトライブラリ最下部カードの見切れ修正**
  * ライブラリのスクロール領域下部に十分な余白（`padding-bottom: 60px`）を確保し、一番下までスクロールした際にカード下端や影が途切れることなく完全に表示されるよう修正しました。

* **Electronレンダラー環境下におけるプロンプトブロックの解消**
  * レンダラープロセスで `window.prompt()` がブロックされて入力不能になる問題に対し、自前のサイバーインライン入力UIを採用することで不具合を解消しました。
