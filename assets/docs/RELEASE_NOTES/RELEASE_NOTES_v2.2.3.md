# ScenePlus+ v2.2.3 Release Notes

**Release Date:** 2026-07-22

v2.2.3 は、操作感の向上と通信の安定性を中心としたパッチアップデートです。以前のバージョンからの細かい不具合修正と、ストリーミング体験の向上が含まれています。

## 🌟 新機能＆ハイライト (Highlights)
- **新しい公式エフェクト同梱:** ジョークエフェクト「Fake BSoD（ブルースクリーン）」が初回インストール時に自動でライブラリに追加されるようになりました。
- **Codeエフェクトの完全ストリーミング対応:** Mode C (Streaming) において、従来のSDK制限を撤廃しました。これにより、純粋なJSモジュールであるCodeエフェクトも相手側のデバイスのメモリ上で直接・超高速にストリーミング実行できるようになりました。

## 🛠 不具合の修正 (Bug Fixes)
- **UIの微細な揺れを修正:** ウィンドウのズーム率が100%付近の際、拡大・縮小処理が無限ループに陥り画面が揺れてしまう現象を修正しました（2%のヒステリシス閾値を導入）。
- **短打鍵（チョン押し）での発火抜けを修正:** 受信側デバイスにて、非同期ロードが完了する前に素早くキーを離してしまった場合、エフェクトが一瞬も表示されずに消滅してしまう（発火しない）問題を修正しました。
- **Syncモード変更のロック不備を修正:** 通信中（Send/Receive）は設定モーダルからのSyncモード（Mode A/B/C）変更を正しくロックするよう修正しました。
- **1.0時代の遺物データの自動クリーンアップ:** インストール時およびアンインストール時に、古い1.0系バージョンの設定データ（`AppData\Roaming\sceneplus`）が存在する場合は自動的にクリーンアップするように改善しました。

## 🔧 開発者向け (For Creators & Developers)
- `NetworkController` と `UIManager` の依存関係（DI）をリファクタリングし、ネットワーク状態に依存したUI制御をより堅牢にしました。
- `Player.ts` の非同期実行プロセスを改善し、強制キャンセル時でも適切にガベージコレクションや `release()` メソッドが走るよう安全性を高めました。
