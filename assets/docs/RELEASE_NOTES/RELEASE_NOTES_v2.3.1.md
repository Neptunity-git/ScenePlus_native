# ScenePlus+ v2.3.1 Release Notes

## 🔧 仕様変更・改善 (Improvements & Architecture Changes)

* **ネットワークロール（役割）の厳格化**
  * プロジェクトのミッションである「シンプルで直感的な操作」を守るため、通信アーキテクチャを見直し、「SEND（参加者・送信側）」と「RECEIVE（スクリーン・受信側）」の1対多の役割分担をより強固にしました。
  * **スキャン時のフィルタリング:** SENDモードの端末は、他の端末からのネットワークスキャン（`SCAN NETWORK`）に対して応答しないようになりました。これにより、接続先リストには正しくRECEIVEモードで待機しているスクリーン（ホスト）のみが表示されます。
  * **直接接続のブロック:** SENDモードの端末に対してマニュアルでIPアドレスを入力して直接接続しようとした場合でも、接続要求を安全に拒否するようになりました。これにより、参加者同士の誤った接続（SEND対SEND）が根本から防がれます。

## 💄 UIの最適化 (UI Optimization)

* **スキャン結果リストの視認性向上**
  * 見つかったデバイスの表示から、余分な「CONNECT」テキストや雷アイコンを削除しました。
  * IPアドレスのみをカードの中央に少し大きめに配置することで、文字のはみ出し（オーバーフロー）を防ぎ、スッキリと洗練されたモダンなデザインになりました。
