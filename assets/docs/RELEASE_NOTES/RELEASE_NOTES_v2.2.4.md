# ScenePlus+ v2.2.4 Release Notes

**Release Date:** 2026-07-23

v2.2.4 は、ネットワーク越しのパラメータ同期不具合の修正、インストーラによるユーザーデータの誤削除防止、およびクリエイター向け公式ガイドのアップデートを含むパッチリリースです。

## 🛠 不具合の修正 (Bug Fixes)
- **リモート発火時のパラメータ同期問題の修正:** OSC経由で他デバイスからエフェクトを発火させる際、変更したパラメータが反映されずデフォルト値で再生されてしまう問題を修正しました。発火時の初期同期に加え、UI操作によるリアルタイムなパラメータ変更も送信先に同期されるようになりました。
- **TypeScript型定義エラーの修正:** `RendererIPC.ts` 等で発生していた `IEffectManager` のプロパティ（`onParamChange` 等）欠落によるビルドエラーを修正し、開発環境の安定性を向上させました。
- **インストーラのデータ削除挙動の修正:** バージョンアップ（上書きインストール）時に、2.x系のユーザーデータが誤って初期化されてしまう深刻な不具合を修正しました。今後は `.html` 形式のファイルを持つ1.0時代の古いエフェクトデータのみを判定して安全にクリーンアップします。

## 📝 ドキュメントの更新 (Documentation)
- **公式クリエイターズガイドの改訂:** 「クリエイター（およびAI）が必ず陥る罠」の項目を新設し、以下の重要な制約事項を追記しました。
  - WASD等でのキーボード入力とシステムトリガーの競合に関する注意喚起と、マウス操作への代替案の提示
  - AIによるコード生成時における、ZIPファイル出力の禁止とコードブロック形式出力の徹底の推奨
