# 🚀 ScenePlus+ v2.2.0 Release Notes

> **ScenePlus+ v2.2.0** では、パフォーマンスを一切低下させずにキー入力をアプリ内へ独占する **C++ ネイティブエンジン** の新搭載、**HiDPI 表示・高解像度環境の徹底最適化**、そしてネットワーク同期モードにおける **全エフェクト 100% 転送対応** を実現した大型アップデートです！

---

## 🌟 主な新機能 & ハイライト

### 1. ⚡ C++ ネイティブ入力独占モード (`Exclusive Keyboard Mode`)
- **完全独立スレッドでの高速処理 (`keyblock.node`)**
  - Node.js のメインスレッドを一切妨げない専用の C++ ネイティブ拡張モジュールを新規開発・統合しました。
  - OS の低レベルフック (`WH_KEYBOARD_LL`) とアトミック共有メモリを使用することで、遅延 0（O(1) 配列検索）でのキー入力遮断を実現。
- **背景アプリへの文字打ち込み防止**
  - 設定画面から「**Block Assigned Keys Only**」を有効にすると、エフェクトエンジン作動時に割り当てられたキー（0〜9, A〜Z）が裏のメモ帳やブラウザへ文字入力されるのを完全にブロックします。
- **万全の安全装置（ハードコードバイパス）**
  - `Esc`、`F1〜F12`（トグルキー含む）、`Windows` キー、修飾キー（`Ctrl`, `Alt`, `Shift`）は常にシステムへ通過するようハードコードされており、操作不能事故を防ぎます。

---

### 2. 🖥️ HiDPI スケーリング & 画面描画の完全補正
- **高解像度ディスプレイにおける座標精度の向上**
  - 4K / 2K などの HiDPI 環境において、論理ピクセル (`window.screen.height`) と `webContents.getZoomFactor()` に基づく正確なカーソル位置計算を実装。
- **Canvas エフェクトの描画はみ出し（ダブルスケール）修復**
  - `Desktop_Virus_Joke` などの Canvas 描画系エフェクトで発生していた画面からの枠はみ出し・拡大オーバーフロー現象を修正しました。
- **画面枠リサイズの固定化 (`resizable: false`)**
  - 全画面オーバーレイの境界付近にマウスを持っていった際、意図せずリサイズカーソルが出現したりウィンドウサイズが変更されたりする問題を完全に無効化しました。

---

### 3. 📡 ネットワーク同期（Mode A / Mode B）の全エフェクト対応
- **オンザフライ (動的) ZIP パッケージ化機能**
  - 送信側 PC の HTTP サーバー (`/api/download/:hash`) において、解凍済みフォルダ内に静的な `.scenefx` ファイルが存在しない場合でも、その場でエフェクト全体（`meta.json`, `index.js`, 各種アセット）を動的 ZIP 圧縮して返却するように拡張しました。
- **100% 確実に同期可能**
  - 自作エフェクトや公式展開済みエフェクトを含め、Mode A (Full Sync / 恒久保存) および Mode B (Guest Sync / 一時保持) で全てのエフェクトが漏れなく他の PC へ転送・同期されるようになりました。

---

### 4. ⚡ 開発・起動パフォーマンスの劇的改善
- **アプリ起動時間の短縮（約10秒 ➔ 1〜2秒）**
  - ビルドプロセスを改善し、`node-gyp rebuild`（毎回全消去コンパイル）から `node-gyp build`（差分高速ビルド）へ最適化。開発時・起動時のストレスを解消しました。
- **タスクバー非表示挙動の固定 (`skipTaskbar: true`)**
  - 状態遷移時やフォーカス時にもタスクバーアイコンが出現しないよう無効化処理を再強化しました。
