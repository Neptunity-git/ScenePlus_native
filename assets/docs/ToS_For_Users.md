# ScenePlus+ユーザー向け利用規約

**【ターゲット】**: アプリをインストールし、エフェクトをあつかうすべての人

ScenePlus+ を起動した瞬間から、あなたのキーボードは単なる入力装置ではなく、空間を支配する「魔法の杖」へと変わります。私たちはあなたに強大な表現力を与えますが、同時に以下の誓いを守ることを求めます。

---

## 第1条：悪意あるエフェクトの使用の禁止
あなたはネットワークの向こう側にある「他者のキャンバス（受信機）」にアクセスする権利を持ちます。しかし、相手のPCをフリーズさせるほど重いエフェクトや、視覚的・精神的なダメージを与える悪意あるエフェクト（ブラクラ等）だと知りながら、他者のデバイスで意図的に発火させる行為は禁止行為として固く禁じます。魔法は、オーディエンスを魅了するために使ってください。

## 第2条：未知のアーティファクトへの警戒
誰かが作った `.scenefx` や `.zip` （配布されるエフェクト）を自分のアプリにインポートすることは、未知の魔法書を開くのと同じです。出所が不明な怪しいエフェクトを安易に同期ネットワークに流し込まないよう、演出家としての「審美眼」と「自己責任」を持ってプレイしてください。

## 第3条：キャンバスの解放
デスクトップはもはや作業するための退屈な板ではありません。すべてのルールを守った上で、あなたは自由に、そして無限に、空間を彩る権利を有します。さあ、最高のショーを始めましょう！
